# Components

The table records the design elements specified in the project brief. Exact materials, dimensions, quantities, ratings, and suppliers must be confirmed from the native CAD, fabrication records, and prototype.

| Component | Function | Information to verify |
|---|---|---|
| 20 L drum pail | Contains the compost batch and rotates horizontally | Actual capacity, material, wall strength, and loaded mass |
| Folding lid | Provides loading and unloading access | Hinge, latch, closure, and retention under rotation |
| Fabricated metal frame | Supports the rotating drum | Section sizes, material, joints, finish, and stability |
| A-frame stand | Provides the main support geometry | Dimensions, bracing, base footprint, and anchoring |
| Bearing block and bearing | Supports a rotating shaft or hub | Bearing type, shaft fit, alignment, load, and maintenance |
| Plain bush | Provides a sliding or locating support where designed | Material, fit, wear, lubrication needs, and exposure |
| Crank arm | Allows the user to apply manual rotation | Length, strength, attachment, and operating clearance |
| Crank grip | Provides a hand-contact surface | Retention, comfort, and pinch clearance |
| Rotor hub / stub | Connects rotating components to the drum | Interface geometry, retention, alignment, and torque transfer |
| Longitudinal brace | Stiffens the support structure | Placement, joint details, and clearance |
| End lid / pail end | Closes or supports the drum end as designed | Fit, sealing intent, retention, and service access |

Names above follow the supplied project file list where possible. Do not infer dimensions or construction details from a filename alone.
